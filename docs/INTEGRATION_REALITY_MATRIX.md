## 1. Executive Status & Engineering Maturity Levels

To preserve absolute engineering transparency, CareFlow classifies each subsystem using the 6-Level Integration Maturity Index:

- **Level 1 (Design)**: Architecture, interfaces, and data schemas designed.
- **Level 2 (Implemented)**: Connector code and data structures implemented in repository.
- **Level 3 (Automated Verified)**: Contract invariants, serialization, and negative paths verified via automated test harnesses.
- **Level 4 (Sandbox Verified)**: Live bidirectional transactions executed against official government/vendor testbeds (e.g., `dev.abdm.gov.in`).
- **Level 5 (Staging / Pilot Verified)**: Verified with authorized facility endpoints in staging/pre-production.
- **Level 6 (Production Approved)**: Formally certified and running live production traffic.

## 3. Data Reality Tiers Enforced in Code & UI

To prevent any reviewer or clinician from mistaking simulated data for live government feeds, every operational datum exposes an explicit `data_reality` tag:

1. **`REAL_EXTERNAL`**: Live data received from an authorized, verified external production system.
2. **`SANDBOX_EXTERNAL`**: Data received from an official government sandbox testbed (`dev.abdm.gov.in`).
3. **`SIMULATED`**: Data generated by local contract mock harnesses or synthetic test fixtures.
