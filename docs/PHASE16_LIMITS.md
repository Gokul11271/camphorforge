# Limits

This phase is an engineering foundation, not production authorization.

Not included:
- Live ABDM credentials
- Live HIE-CM transactions
- Production patient data
- Government endpoint hard-coding
- Production certificates
- Clinical use

Before production:
- Confirm current official API/protocol versions.
- Complete sandbox testing and certification/onboarding.
- Validate all FHIR resources against the exact approved IG package.
- Perform security/VAPT and privacy review.
- Validate clinical workflow with responsible health authorities.
